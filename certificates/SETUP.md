# Open the interactive certificate wall

The GitHub README displays the animated scrolling wall. The certificate gallery below it displays the original certificate images.

For the interactive hover, parallax and full-image viewer at `https://Marwane-Haddane.github.io/Marwane-Haddane/certificates/`:

1. Open this repository’s Settings → Pages.
2. Under Build and deployment, select **Deploy from a branch**.
3. Choose **main**, **/ (root)**, then Save.

The self-contained gallery can also be opened locally from `certificates/index.html` with its adjacent `images` folder. It supports search, issuer filters, keyboard navigation, and reduced motion. No external statistics-image API is used.
