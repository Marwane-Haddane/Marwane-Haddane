# Use this profile pack

1. Extract the ZIP.
2. Open `preview.html` to review the animations and switch dark/light themes.
3. Open your `Marwane-Haddane/Marwane-Haddane` GitHub repository.
4. Upload `README.md`, the complete `assets` folder, and the `certificates` folder to the root of the repository. Commit the changes.

The SVG artwork animates directly in the GitHub README. It includes dark/light variants and respects reduced-motion preferences. Local GIF alternatives are also provided: `assets/header.gif`, `assets/certifications.gif`, `assets/projects.gif`. For example, replace the header picture block with `<img src="assets/header.gif" width="100%" alt="Marwane Haddane">` if you prefer a GIF.

The certificate gallery works from `certificates/README.md` on GitHub. `certificates/index.html` is an additional standalone gallery; opening an HTML source file on GitHub does not run it. GitHub Pages hosting can be configured separately if you want a public interactive gallery URL.

Only two credentials with evidence on the portfolio are included. No fabricated dates, certifications, statistics, or APK download links are used. Add public APK release links to the apps table when available.

The visual cards summarize existing credentials; the original certificate images and official verification links are in the gallery. They are not replacement certificates.
